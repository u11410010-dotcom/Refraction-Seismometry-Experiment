## 互動式網頁

直接用瀏覽器開啟 `index.html` 即可（無需安裝任何套件、可離線使用），內容包含四個章節：

1. **儀器介紹** — 可點擊／自動播放的測線配置圖、爆點資訊面板、疊加次數長條圖
2. **原理介紹** — 直接波／折射波／反射波／面波四種波的動畫示意與可調參數的 t-x 模擬器
3. **資料分析** — 12 發炮集剖面（wiggle）、t-x 曲線與線性回歸、每發表觀速度、平均頻譜、逐炮品質表
4. **心得感想** — 打字機效果的第一人稱感言、體力數據、時間軸、可自行撰寫並儲存的震測日誌

頁面內所有圖表都由 `202610_UTELS.sgy` 實際計算而得，資料來源與重現步驟列於頁面附錄。

## 處理與使用建議

1. 優先使用 `202610_UTELS.sgy` 進行一般震測處理（濾波、振幅回復、速度分析、成像等）。
2. 若需保留儀器原始資訊，使用 `seg2/*.dat`；其头部含增益、叠加次數、採集時間等。
3. `skew = -0.000125748 s`，處理時注意樣本對齊。
4. `.geom` 中的座標欄位含佔位 `0.0`，若用於 inversion/refraction software，需先補齊測區幾何。
5. `UTELS.pdf` 為向量圖形 PDF，若需 OCR 或重新標註，建議以 `UTELS.ps` 或原始 SEG-Y 重新繪圖。
6. 資料未附授權條款；本 README 僅依現有檔案內容整理說明。
